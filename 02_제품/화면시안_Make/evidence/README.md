# 구좌 음식점 통합 프로토타입

Figma Make의 로그인·사이드바·상단바·아이콘·Pretendard 글꼴과 원본 CSS를 재사용한다. `figma-ui.js`는 원본 번들의 로그인·셸 마크업을 추출한 파일이고, `figma.css`는 원본 CSS와 동일하다. `app.js`가 실제 집계와 기존 검증된 저장 기능을 각 화면에 연결한다. 이전 번들의 가상 성과·예시 수치·CSV 등록 동작은 실행하지 않는다.

첫 방문은 로그인 화면이다. **계정 정보 채우기 → 로그인**으로 시작한다. 사업체 역할은 `cafe@example.com`, 서비스 역할은 `admin@example.com`이며 화면에 시연 비밀번호를 표시한다. 실제 인증·가입·권한 분리는 없다. 실제 비밀번호를 입력하지 않는다. 두 역할은 같은 브라우저 저장 공간을 공유한다.

| 화면 | 실제 자료 및 연결 |
| --- | --- |
| 한눈에 보기 | 12개월 일수 보정 계절지수, 고객군 소비 비중, 최근 동기간 증감, 저장 계획 수 |
| 홍보 제안 | 선택 월이 속한 분기의 3개 월·고객군별 실제 근거와 검토 초안, 계획 작성 연결 |
| 계획 작성 | 선택 이유·실행안·대상 월 날짜·성과 지표와 저장 당시 근거 |
| 3개월 홍보 일정표 | 분기 선택, 사용자 저장 계획만 표시, 수정·삭제·기록 연결 |
| 실행 결과 조회 | 사용자가 입력한 기록, 0과 미측정 구분, JSON 내보내기 |
| 지역 분석 | 비수기 안정성·규칙 비교·고객군·시간대·최근 동기간·관광지 후보·출처 |
| 자료·기준 확인 | 서비스 운영자용 원천 4종·기간·규칙·한계의 읽기 전용 확인 |

## 실행과 지원 범위

저장소 최상위에서 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1`로 실행한다. 기본 주소는 `http://127.0.0.1:8766/화면시안_Make/evidence/index.html`이다. 공개 평가는 https://nenongkim.github.io/jeju-marketing-demo/ 에서 열며 main의 허용 파일 변경은 자동 배포한다.

지원 범위는 구좌읍·음식점업·2026년 12개 월·3개 고객군이다. 계절성은 2023년부터 2025년까지, 최근 비교는 2025·2026년 1월부터 8월까지다. 대상 월과 다른 날짜로 계획을 저장하거나 내보낼 수 없다. 실제 실행일은 미래 날짜를 허용하지 않으며 준비 일정과 구별한다.

## 저장과 실행 기록

- 월·고객군을 확인하고 선택 이유·실행안·날짜·성과 지표를 입력해 저장하면 일정에 나타난다.
- 같은 월에도 새 계획을 여러 개 작성할 수 있다. 계획 수정은 ID와 기존 실행 기록을 유지한다.
- 계획마다 저장 당시 데이터 근거를 보관한다. 새 데이터와 자동으로 섞지 않는다.
- 실행 상태·실제 실행일·활동·시간·클릭·예약·쿠폰·측정 조건을 직접 기록한다. 빈 숫자는 null이며 확인된 0과 다르다.
- 실행 완료는 날짜와 활동 내용이 필요하다. 기록은 사용자 입력이며 검증된 마케팅 효과로 표시하지 않는다.
- 전체 계획·기록 내보내기 및 개별 저장 근거 보기에서 JSON을 제공한다. 다운로드가 안 되면 화면 JSON을 복사할 수 있다.
- 계획 삭제는 두 번 확인하며 해당 실행 기록도 함께 삭제한다. 필요한 내용은 먼저 내보낸다.

저장은 현재 브라우저 localStorage의 `ijto-gujwa-workspace-v1`에 한정된다. 시연용 로그인은 있지만 실제 인증·서버 저장·기기 간 동기화는 없다. 이전 예시 서비스와 사례의 저장 내용은 자동 가져오지 않고 원래 키에 보존한다. 손상된 저장 데이터를 발견하면 덮어쓰기를 중지한다. 저장 실패 시 입력과 기존 상태를 유지한다. 미저장 계획·실행 기록은 메뉴 이동 시 메모리에 유지하며 입력 중 새로고침·페이지 이탈은 브라우저 경고를 요청한다. 브라우저가 경고를 생략하거나 사용자가 이탈을 선택하면 미저장 입력은 사라질 수 있으므로 저장 후 이동한다. 수정 계획별 초안은 같은 월의 다른 계획과 분리한다. 계획 수정 시 최초 저장한 분석 근거와 실행 기록을 유지한다. 저장 근거 보기는 다운로드하지 않으며 전체 내보내기는 저장 완료된 값만 포함한다. 뒤로가기·앞으로가기는 메뉴 이동 이력을 따른다.
