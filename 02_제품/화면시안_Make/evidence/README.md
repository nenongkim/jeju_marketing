# 구좌 음식점 실제 데이터 사례

기존 Make 시안과 HTML 시안의 고정 링크에서 이 화면으로 이동한다. 독립 인증이 필요한 개인 자료는 포함하지 않는 공개 지역 통계 시연이다. 기존 화면은 예시 자료로 유지하며 실제 근거 사례와 구분한다.

저장소 최상위에서 다음 명령으로 실행한다.

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory 02_제품
```

브라우저 주소: `http://127.0.0.1:8766/화면시안_Make/evidence/index.html`

기본 사례는 구좌 음식점의 2026년 12월 계획이다. 12개 월·3개 고객군을 변경할 수 있다. 분석에는 2023년부터 2025년까지의 실제 자료만 사용한다. 날짜·실행안·선택 이유·확인할 성과 지표를 작성하고 계획을 저장하거나 근거와 함께 내보낼 수 있다. 저장은 이 브라우저의 localStorage에 한정된다. 실제 광고·예약·매장 운영을 실행하지 않으며 매출 효과와 사용자 평가는 미측정이다.

## 화면의 흐름

1. 월별 일수 보정 지수·연도별 반복 여부·기준 민감도 확인
2. 해당 월의 고객별 소비금액 비중과 계절성 확인
3. 선택 고객군의 같은 월 시간대 분포 및 관광객 전체의 같은 월 장소 후보 확인
4. 운영자가 판단 이유와 실행안을 기록하고 저장 또는 JSON 내보내기

내보내기는 브라우저 다운로드를 요청하고 화면에도 동일 JSON을 표시한다. 앱 내 브라우저가 파일을 저장하지 않으면 표시된 JSON을 복사해 보관할 수 있다. 로컬 시연에서 자동 다운로드 완료까지 확인한 것은 아니다.

원천 합계 불일치, 관측 없는 시간대, 장소의 현재 영업·거리 미확인 상태는 화면에 표시한다. 낮은 수요 판정은 운영상 기준이며 통계적 유의성이나 미래 성과 예측이 아니다. 시연 링크의 공개 배포와 원천별 공개 이용허락 검토는 별도 작업이다.

## 재현·검사

```powershell
python 07_원천/ijto_20261027/scripts/strengthen_ijto_case.py --data-root 'C:/Users/User/OneDrive/문서/ChatGPT/공모전/data_collection' --repo-root .
node 02_제품/화면시안_Make/evidence/case-data.test.cjs
```

첫 명령은 원본 4개 해시 검증 후 JSON과 분석 증빙을 생성한다. 두 번째 명령은 자료 형식과 오류 차단, 월·시간대 정합성, 결측 보존을 검사한다. 브라우저 검증 기록은 분석 보고서 6절에 있다.

기존 Pages 워크플로는 Make 폴더 변경 시 실행되도록 이미 설정되어 있다. 이 폴더는 상대 경로로 자체 데이터를 읽으므로 해당 게시 범위에 포함된다. 배포 권한·요금제·Pages 설정은 변경하지 않았다.
