# 실제 데이터 시연 묶음

`ijto-demo-20261027.json`은 2026년 10월 27일 수집한 제주관광빅데이터플랫폼 CSV의 파생 통계다. 스키마 버전은 `1.0.0`이다. 기존 프로토타입에는 아직 연결하지 않았다.

| 필드 | 내용·단위 |
| --- | --- |
| `regions` | 43개 읍면동 |
| `regions[].codes` | 원천별 코드, 숫자로 변환하지 않는 문자열 |
| `regions[].seasonality` | 12개월 방문·음식점 소비 지수, 연평균=1 |
| `visits_daily_index`, `restaurant_daily_index` | 월별 일수 보정 지수 |
| `visits_year_min`, `visits_year_max` | 3개 연도 지수의 관측 범위, 신뢰구간 아님 |
| `regions[].visits_ytd` | 2025년 및 2026년 1월부터 8월까지 비교, 변화율과 비중은 % |
| `regions[].restaurant_customer_mix` | 2025년 음식점 카드 소비금액 고객별 비중, % |
| `hourly_profiles` | 애월·구좌의 월·고객구분별 시간대 소비금액 비중, % |
| `place_candidates` | 2025년 또는 2026년 1월부터 9월까지 관광객 차량 도착 수, 원천 경고 포함 |
| `sources`, `source_mapping` | 공식 출처 URL과 각 자료의 사용처 |
| `periods`, `method`, `warnings` | 기준 기간·계산법·화면 표시할 주의사항 |

화면에서는 기준 기간·출처·자료 단위를 함께 표시한다. 지수 0.8은 해당 연도 월평균보다 20% 낮은 수준이며 ‘전년 대비 20% 감소’가 아니다. 이름이 다른 원천 코드를 숫자 부분 일치로 결합하지 않는다.

시간대별 비중의 분모는 해당 지역·월·고객구분의 2023년부터 2025년까지 음식점 소비 합계다. 일부 시간대가 없으면 결측으로 취급하고 자료 확인 없이 0으로 채우지 않는다. 도 전체 성·연령 자료를 해당 가게의 고객 구성으로 붙이지 않는다.

장소 후보는 연도별 순위 참고용이다. 추천 거리·제휴 관계·연도 간 성장률이 아니다. `status`와 `warnings`를 숨기지 않는다. 공개 배포 조건은 출처별 확인이 필요하다.

JSON은 정적 HTTP 서버에서 읽을 수 있다. 기존 앱의 상대 경로와 배포 기본 경로에 맞춰 로더를 연결해야 한다. `schema_version`이 다르거나 필수 데이터가 없으면 임의 예시값으로 대체하지 말고 오류·자료 없음 상태를 표시한다.
