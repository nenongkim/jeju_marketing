# 공개 시연 전체 점검 및 수정 — 2026-10-28

대상: https://nenongkim.github.io/jeju-marketing-demo/

## 발견하여 수정한 항목

- 대시보드 일정이 10월부터 12월로 고정됨 → 선택한 월의 분기와 일정 보기 목적지를 일치시킴
- 일정표의 저장 계획이 월별 칸 밖에 나열됨 → 해당 월 안에 배치하고 빈 달 안내 추가
- 메뉴를 접고 이동하거나 너비를 초기화한 뒤 접근성 상태가 실제 표시와 달라짐 → 너비·펼침 상태·버튼 이름 동기화
- 모바일 메뉴를 연 채 데스크톱 크기로 전환하면 본문이 비활성 상태로 남을 수 있음 → 전환 시 메뉴와 본문 상태 복구
- 다른 화면에서 로그아웃할 때 숨겨진 계획 필드가 현재 월 초안을 덮어쓸 수 있음 → 실제 표시 중인 계획만 캡처
- 원본의 ‘예시 계정’ 접근성 문구 → ‘시연용 계정’으로 명확화

## 확인 범위

- Figma 원본 공개 화면과 로그인·브랜드·사이드바·대시보드 구조 시각 비교, 원본 figma.css 유지 및 Pretendard 로딩 확인
- 사업체·서비스 운영자 로그인, 월·고객군 선택, 홍보 제안과 근거 상세, 계획 저장, 월별 일정, 실행 기록, 근거 JSON, 점검용 계획 삭제
- 메뉴 접기 후 이동, 초기화, 모바일 메뉴, 화면 크기 전환, 로그아웃 후 미저장 초안 복원
- 데이터·최근 동기간·워크플로·36개 제안 자동 검증 및 12개월 대시보드 분기 회귀 검증
- 공개 파일 허용목록 검증. 원본 CSV·신청서는 계속 비공개

## 원본과 의도적으로 다른 부분 및 한계

- 원본의 애월 예시 카페·가상 차트·성과 대신 구좌 음식점업 공식 집계를 사용함
- 실제 자료가 없는 지역·업종 선택, 서버 인증·CSV 업로드 기능을 제공하는 것처럼 표시하지 않음
- 분석 상세는 출처·기간·관측 누락과 해석 한계를 보여주므로 원본의 모든 내부 화면을 픽셀 단위로 복제한 것은 아님
- 임시 로그인 계정은 시연을 위한 값이며, 사업 실적의 예시 데이터와 구분함
- 실제 사용자 평가와 매출 효과는 미측정. 저장은 브라우저 내부이며 다중 기기 서버 동기화가 아님
- 로컬 검증 후 커밋·자동 배포하고 공개 사이트에서도 다시 점검함. 배포 결과는 최종 작업 보고에 기록
