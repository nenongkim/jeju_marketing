# 실제 사용자 평가 진행 절차

현재 상태: 미실시. 이 문서는 평가 계획이며 사용자 수·만족도·매출 효과를 증명하지 않는다.

## 모집과 준비

구좌 음식점 운영자 또는 마케팅 담당자를 우선 모집한다. 가능하면 3명부터 5명까지 진행하되 실제 참여 인원만 보고한다. 학생·지인은 별도로 분류한다. 참여자에게 목적과 약 25분 소요, 중단 가능 여부를 설명하고 기록 동의를 확인한다. 이름·전화번호·매장 매출 원장은 기록하지 않고 P01 같은 식별자를 사용한다. 녹음·공개 인용은 별도로 동의를 받는다.

진행자는 브라우저를 열어 데이터가 정상 표시되는지 확인하고, 기존 연습 계획을 실제 평가 결과와 혼동하지 않도록 참여자마다 별도 브라우저 프로필을 사용한다. 원본 수치는 동일한 날짜의 자료를 사용한다. 평가자 설명과 기능 오류를 모두 기록한다.

## 과제와 측정

1. 참여자의 역할·운영 경험·데이터 도구 사용 경험을 기록한다. 처음 화면을 보여주기 전 평소 계획 방법을 질문한다.
2. 안내문을 그대로 읽는다: “구좌 음식점의 12월 마케팅을 검토하세요. 수요 상황과 고객군을 선택한 이유, 검토할 시간 구간, 추가 확인 사항을 적고 계획을 저장한 다음 근거를 내보내세요. 정답 고객군은 없습니다.”
3. 안내문을 읽은 직후부터 내보낸 JSON을 확인할 때까지 시간을 잰다. 10분이 지나면 종료하며 미완료로 기록한다. 도움 요청·개입 시각과 내용을 기록한다. 실패·중단을 평균 시간에서 조용히 제외하지 않는다.
4. 수행 여부를 각각 기록한다: 12월 선택, 고객군 비교, 2026년 동기간 확인, 시간 구간 확인, 선택 근거 작성, 저장, 내보내기. 도움 없이 완료/도움 후 완료/미완료를 구별한다.
5. 화면을 보며 아래 해석 질문을 묻는다. 각 항목은 핵심을 맞히면 1점, 그렇지 않으면 0점으로 기록한다. 처음 답변을 기록한 뒤에만 정답을 설명한다.
6. 계획의 근거를 0점부터 3점까지 평가한다. 계절성, 고객군, 최근 동기간의 범위를 각각 올바르게 활용하면 항목당 1점이다. 광고 효과를 이미 입증했다고 쓰면 별도로 오해를 기록한다.
7. 이해하기 쉬운 정도와 실무 유용성을 각각 1점부터 5점까지 묻고 이유를 그대로 기록한다. 실제 채택 여부는 미결정/검토 예정/계획에 반영/실행 완료로 구분한다. 검토 의향을 실행 실적으로 합산하지 않는다.

| 지역 방문 집계나 카드 이용건수가 우리 가게 고객 수인가요? | 아니며 지역 집계·거래 건수와 고유 매장 고객을 구별 |
| 2026년 1월부터 8월까지 증감률로 12월 매출을 확정할 수 있나요? | 아니며 다른 기간이고 예측·효과 검증이 아님을 설명 |
| 관측 자료가 없는 시간은 이용이 0건인가요? | 아니며 미관측과 0을 구별 |

## 시간 절감 비교를 주장하려면

이번 기본 평가는 도구 사용성만 측정한다. 시간 절감률을 주장하려면 별도 비교를 사전에 설계한다. 동일한 원천 수치가 담긴 정적 표와 프로토타입을 비교하고, 참여자별 순서를 번갈아 배정한다. 12월과 3월의 동일 구조 과제를 교차 배정하며 동일한 제한시간·도움 규칙을 적용한다. 표 준비 시간 포함 여부를 사전 기록한다. 월별 난이도와 반복 학습, 소수 편의표본의 한계를 보고하고 전후 차이를 인과 효과로 단정하지 않는다. 비교를 하지 않았다면 시간 절감은 미측정으로 둔다.

## 정리

[개별 기록](개별_평가기록_양식.md)을 참여자마다 복사하고 [결과 집계](결과_집계_양식.md)에 옮긴다. 실제 기록은 동의 범위를 확인한 뒤 저장하며 원본 서명·연락처는 Git에 넣지 않는다. 실패·부정적 의견도 포함한다. 기능 시험 기록을 실제 사용자 평가에 넣지 않는다. 매출·고객 증가 효과는 별도 실행 및 비교 관측 없이는 미측정으로 유지한다.
