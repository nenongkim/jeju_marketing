# 실제 사용자 평가 안내문

안녕하세요. 제주 관광 데이터를 보고 음식점 홍보 계획을 세우는 시연 사이트를 평가 부탁드립니다. 잘 사용하는지 시험하는 것이 아니라, 화면이 이해하기 쉽고 실제 업무에 도움이 되는지 확인하려는 평가입니다. 불편하거나 이해되지 않는 점을 그대로 알려주세요. 약 25분이 필요하며 언제든 중단할 수 있습니다.

**시연 링크:** https://nenongkim.github.io/jeju-marketing-demo/

## 1. 접속과 로그인

1. 가능하면 PC의 Chrome 또는 Edge에서 링크를 여세요. 휴대전화로 참여해도 되며 사용 기기를 알려주세요.
2. 로그인 화면에서 **사업체 운영자 → 계정 정보 채우기 → 로그인**을 누르세요.
3. 직접 입력한다면 이메일 `cafe@example.com`, 비밀번호 `JejuDemo26!`입니다. 모두에게 공개된 시연용 정보입니다. 회원가입이나 본인 비밀번호 입력은 필요하지 않습니다.
4. 다른 화면부터 나오면 이미 로그인된 상태입니다. **한눈에 보기**로 이동하세요. 서비스 운영자로 되어 있다면 로그아웃 후 사업체 운영자를 선택하세요.

계획과 기록은 지금 사용하는 브라우저에만 저장됩니다. 평가가 끝나 자료를 보내기 전까지 같은 브라우저를 사용하고, 사이트 데이터나 작성한 계획을 지우지 마세요. 이름·연락처·실제 매출 등 개인·사업체의 민감한 정보는 입력하지 마세요.

## 2. 해볼 과제

상황: **“구좌읍 음식점의 2026년 12월 홍보를 검토합니다.”** 정답 고객군이나 정답 계획은 없습니다. 실제로 운영할 수 있을지 생각하며 본인의 판단을 적어주세요. 실제 광고를 게시하거나 매출을 입력할 필요는 없습니다.

| 순서 | 할 일 |
| --- | --- |
| 1. 자료 살펴보기 | **지역 분석**에서 **분석할 월: 12월**을 선택하세요. **살펴볼 고객군**을 바꿔 비교하고, 계절 흐름·최근 동기간·시간대 자료를 확인하세요. |
| 2. 제안 고르기 | **홍보 제안**에서 **대상 월: 12월**과 원하는 고객군을 확인하세요. 10월부터 12월 카드 중 **12월 카드의 근거 상세보기**를 확인하고, 돌아와 **계획 작성**을 누르세요. |
| 3. 내 계획 작성 | 고객군·시기 선택 이유, 검토할 실행안, 2026년 12월 안의 준비 일정, 확인할 성과 지표를 본인 생각에 맞게 적고 **계획 저장**을 누르세요. 자동으로 채워진 문장을 그대로 따를 필요는 없습니다. |
| 4. 일정과 저장 근거 확인 | **3개월 홍보 일정표**에서 **확인할 분기: 2026년 10월부터 12월**을 선택하고 12월 칸에 저장된 계획을 찾으세요. **저장 근거 보기**를 확인하세요. |
| 5. 파일 받기 | **전체 계획·기록 내보내기**를 누르세요. `구좌_계획과실행기록.json` 파일이 저장됩니다. 다운로드가 안 되면 화면의 JSON 내용을 전부 복사해 메모장에 저장하거나 평가 요청자에게 보내주세요. |

위 과제는 시작부터 파일 확인까지 최대 10분간 진행합니다. 막히면 도움을 요청해도 됩니다. 10분이 지나면 완료하지 못한 단계와 이유를 기록하고 멈추세요. 실패도 중요한 평가 결과입니다.

**이후 추가 확인(핵심 과제 시간과 별도로 기록):** 계획이 저장되었다면 **계획 수정**으로 내용을 조금 수정·저장하고, **실행 기록 작성**을 열어보세요. 실제 홍보를 하지 않았다면 **진행 상태: 미착수**, 실제 실행일·활동 내용·클릭·예약·쿠폰 수는 빈칸으로 두세요. 측정 방법·기간·증빙과 해석 한계에 “사용성 평가에서 기록 기능만 확인함. 실제 홍보 미실행”이라고 적고 **실행 기록 저장**을 누르세요. **실행 결과 조회**에서 확인한 뒤 다시 **전체 계획·기록 내보내기**를 눌러 마지막 파일을 보내주세요. 과제를 끝낸 것을 **실행 완료**로 표시하지 마세요.

## 3. 평가 후 보내주실 자료

이 안내를 보내드린 사람에게 **같은 대화방이나 전달받은 연락 수단**으로 아래 자료를 보내주세요. 사이트에서 자동 전송되지 않습니다.

- 마지막으로 내보낸 **계획·실행 기록 JSON 파일**. 만들지 못했다면 어느 단계에서 막혔는지 알려주세요.
- 아래 **간단 회신 양식**을 채운 메시지. 진행자와 함께 평가했다면 진행자가 기록한 내용을 확인해주셔도 됩니다.
- 저장한 일정이나 실행 결과 화면 **1장**, 오류가 있었다면 오류 화면도 부탁드립니다. 개인 정보나 다른 창이 보이지 않게 가려주세요. 캡처가 어려우면 화면 이름·누른 버튼·문제 내용을 글로 보내주세요.

### 간단 회신 양식 — 복사해서 작성

```text
참여자 ID(요청자가 알려준 P01 등):
평가 날짜 / 기기·브라우저:
음식점 운영·마케팅 경험(없어도 괜찮습니다):
익명 평가 기록에 동의: 예 / 아니오
익명 의견 인용에 동의(선택): 예 / 아니오
로그인: 혼자 완료 / 도움 후 완료 / 못함
핵심 과제 시작·종료 시각 또는 걸린 시간(측정 못했으면 미측정):
완료한 마지막 단계(1부터 5 중):
도움을 받은 단계와 내용:
선택한 고객군·시간 구간과 그 이유:
실행 전에 추가로 확인할 점:
계획 수정 / 실행 기록 확인: 각각 완료 / 미완료
이해하기 쉬운 정도: 1(매우 어려움)부터 5(매우 쉬움) 중 __
실제 업무에 도움이 되는 정도: 1(전혀 도움 안 됨)부터 5(매우 도움 됨) 중 __
위 점수를 준 이유:
좋았던 점 / 불편하거나 고칠 점:
오류가 난 화면·버튼과 상황(없으면 없음):
실제 활용 의향: 미결정 / 검토 예정 / 실제 계획에 반영 / 실제 실행
첨부: JSON 파일 / 화면 캡처 / 전달하지 못한 자료와 이유
```

평가용 계획 저장만 했다면 ‘실제 계획에 반영’이나 ‘실제 실행’으로 적지 않아도 됩니다. 평가 종료 후 진행자가 자료 해석에 관한 짧은 질문 4개를 추가로 드릴 수 있습니다.

기준: 2026-10-28 공개 시연, 소스 `43b17db` / 공식 자료 수집일 2026-10-27. 실제 사용자 평가 결과와 매출 효과는 아직 미측정입니다.
